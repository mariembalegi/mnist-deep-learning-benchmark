# MNIST Handwritten Digit Recognition — Deep Learning Benchmark

## Overview

This project explores handwritten digit recognition using the MNIST dataset. It implements and compares Multi-Layer Perceptron (MLP) and Convolutional Neural Network (CNN) architectures using TensorFlow and Keras.

## Key Features

- MNIST data preprocessing and normalization
- MLP and CNN model implementation
- Dropout regularization and Early Stopping
- Training and validation performance visualization
- Model evaluation using accuracy, confusion matrices, and classification reports

## Technologies

Python, TensorFlow, Keras, NumPy, Scikit-learn, Matplotlib, Seaborn, Jupyter Notebook.

## Dataset

MNIST — 70,000 grayscale handwritten digit images across 10 classes (0–9).

## How to Run

Install the required Python libraries, open the Jupyter notebook, and execute the cells in order.
